Bookmarks

An unattended list of some tools and online pages that I find extremely useful.

  • dogbin. To take notes and share it with other people
  • katbin. A fork of deletescape's dogbin
  • photopea. Edits images online
  • squoosh. Compresses PNG, JEPG and WEBP files, works offline
  • filegarden. Hosts and upload images and other files, useful for this site
  • beatufier. Beautifies JS and CSS code
  • alphabetizer. Alphabetizes, order and other tools
  • framebird. Converts across different image filetypes
  • html validator. Validates HTML code
  • dns lookup. Lookups DNS records from any site
  • dns checker tool. Identifies DNS resolvers, checks DNSSEC validation, etc
  • diffchecker. Git-style commit diff checker but for any text
  • contrast checker. Checks whether color contrast passes AA and AAA
  • monochrome. Streams and downloads lossless music from Tidal and Qobuz
  • lucida. An alternative to download lossless music
  • squiwtf. Downloads music up to 24-bit 192kHz from varios sources
  • vertexmovies. Streams movies and series with download support
  • vertexmovies bookmark. Tells you whether upper link has moved domains so you never lose access to it
  • cineby. Alternatively streams movies and series with torrent support
  • autounattend.xml. Creates answer files to perform unattended installations of Windows
  • massgrave. Open-source Windows and Office activator. Also downloads ISOs from official sources.
  • ungoogled. Official site for downloading the most clean chromium-based browser
  • send vis.ee. Lets you share encrypted files with a link that automatically expires. Open source
  • qr generator. Generates QR code with plenty of options, allows SVG exports
  • shields. Generates consistent and legible badges in SVG and raster format
  • acbbjprojek. Access open source projects, documentation and files realted to the organization
  • axbbjprojek. Explored open source projects and allows access to the heart of bbjprojek
